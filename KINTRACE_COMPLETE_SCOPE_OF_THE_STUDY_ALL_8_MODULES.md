# KINTRACE: SCOPE AND LIMITATIONS OF THE STUDY
**Deliverable:** Chapter 1: Scope and Limitations (STI Capstone Manuscript)  
**Standard:** 100% Pure Monochrome Black-and-White (`#000000`), Times New Roman, 1.5" Left Binding Margin, Single-Level `a. Title – Description.` Format  

---

## Scope of the Study

This study focused on the design, development, and implementation of the Mobile-Based Genealogical Bloodline Tracing System (KinTrace), an Android-based mobile application that enables Filipino families to document ancestral heritage, manage multi-generational records, calculate consanguinity degrees under Philippine civil law, and visualize family trees in real time. The application was developed natively for Android using Android Studio and Kotlin, supported by Google Cloud Firebase for authentication, real-time database synchronization, and cloud data storage.

The system encompasses eight (8) core operational modules. The specific features, capabilities, and boundaries of each module are detailed below:

### 1. User Management and Security Module

The User Management and Security Module manages user onboarding, email verification, session authentication, role permissions, clan governance, and privacy controls for sensitive family records in accordance with the Data Privacy Act of 2012 (Republic Act No. 10173). This module ensures that only verified users can access family workspaces and that living relatives' details are protected from unauthorized viewing or accidental deletion. Specifically, this module covers the following features:

* **a. Account Registration, Email Verification, and Login –** Allows new users to create an account using their full name, email address, and password, validates that all fields are properly formatted, and sends a verification link to the user's email that must be confirmed before accessing the family workspace.
* **b. Disposable Email Shield and Domain Shortcuts –** Blocks known temporary or fake email providers during registration to protect family tree integrity, and provides one-tap email domain buttons (such as @gmail.com, @yahoo.com, @outlook.com, and @icloud.com) for faster typing.
* **c. Password Security Meter and Account Recovery –** Enforces an 8-character password policy requiring uppercase, lowercase, and numeric characters with a live strength meter, and provides a forgot-password screen that sends a password reset link to the user's registered email.
* **d. Mandatory Privacy and Terms Agreement –** Presents an interactive Terms of Service and Data Privacy agreement covering Republic Act No. 10173 and Philippine Family Code rules, requiring the user to check the consent box before registration can proceed.
* **e. Role-Based Access Control and Pending Requests Hub –** Assigns members as Owner, Editor, or Viewer to restrict unauthorized changes, and provides the Tree Owner with a unified hub to approve or reject join requests, Editor role upgrade requests, and member restoration requests.
* **f. Living Relative Privacy and Clan Security Controls –** Automatically conceals the exact birthdates of living family members by displaying an approximate age, and gives the Tree Owner four privacy toggles to control living member visibility, photo visibility, export permissions, and tree discoverability.
* **g. Clan Profile Settings and Slide-to-Delete Safety –** Allows the Tree Owner to update the clan name, description, ancestral origin, and heritage tags, or transfer tree ownership and permanently delete the clan workspace using a slide-to-confirm safety bar.
* **h. Demo Account Vault and System Administration Portal –** Provides pre-configured demo accounts on the login screen for instant evaluation of different roles, along with a dedicated Admin Portal for reviewing 50-member quota expansion requests, viewing global platform counts, managing registered accounts, and broadcasting system advisories.

### 2. Dashboard Module

The Dashboard Module serves as the central home screen of the KinTrace application upon logging in. It displays real-time statistics about the active family tree, monitors tree completeness, presents quick navigation shortcuts to core features, and provides built-in learning guides for relatives of all ages. Specifically, this module covers the following features:

* **a. Dashboard State Display, Tree Creation, and Invite Code Joining –** Automatically switches between an Empty State and a Populated State, guiding users without a tree to either create a new family tree (with age-appropriate founder role templates) or join an existing family tree using a 6-character invite code or a 48-hour reunion guest pass.
* **b. Family Tree Switcher and Collaborator Activity Check –** Allows users who belong to multiple families to switch between different clan workspaces, create a new tree, or join another tree through a tree selection popup dialog, while automatically checking for 14-day collaborator inactivity for the Tree Owner.
* **c. Real-Time Clan Counters and Detailed Insights Screen –** Computes and displays live counts of total family members, generations deep, marriage unions, and living versus deceased relatives, and opens a detailed Insights screen showing a gender distribution bar, generational breakdown (Gen 1 to Gen 4+), and a profile completeness percentage score.
* **d. Clan Health and Missing-Parents Alert Banner –** Scans the active family tree and displays a warning banner on the home screen whenever relatives have unrecorded parents, providing a one-tap shortcut that opens the member directory pre-filtered to those incomplete records.
* **e. Quick Action Shortcuts and Floating Bottom Navigation –** Provides one-tap cards and a floating bottom navigation bar to add relatives, open the interactive tree canvas, browse the member directory, trace bloodlines, export reports, switch between Dark and Light heritage themes, and check for in-app APK updates.
* **f. Recent Activities Log and Restoration Requests –** Displays a chronological feed of recent family tree events (added, edited, and deleted members) with filter chips, allowing Owners to restore deleted relatives directly and Editors to submit a restoration request to the Owner.
* **g. Kin Academy Learning Hub and Filipino Kinship Dictionary –** Provides 10 interactive genealogy learning modules with category filters and reading progress tracking, alongside a searchable Filipino-to-English kinship dictionary (Kamag-anak Reference Guide) that explains legal consanguinity degrees.

### 3. Family Information Management Module

The Family Information Management Module handles the creation, editing, searching, filtering, archival recovery, and cross-branch merging of individual family member records. It ensures that biological and adoptive parentage, chronological marriages, and life histories are recorded accurately without data loss. Specifically, this module covers the following features:

* **a. Add and Edit Family Member Records –** Allows authorized users to create and update relative profiles with complete personal details (first name, middle name, last name, suffix, gender, civil status, birth date, birthplace, vital status, death date, death place, and biography), while tracking the tree's 50-member capacity limit and allowing Owners to request a quota expansion.
* **b. Biological and Adoptive Parentage Linking –** Connects relatives by selecting biological fathers and mothers as well as adoptive fathers and mothers from searchable dropdown lists, automatically creating matching parent-child links while warning users if a selected parent is already linked as a step-parent or in-law.
* **c. Multiple Marriages, Co-Parent Selection, and Duplicate Detection –** Records current and former spouses with marriage status labels, prompts the user to select the specific other biological parent when assigning children, and displays a side-by-side comparison alert if a newly entered member closely matches an existing relative.
* **d. Searchable Member Directory –** Displays all clan members in an organized directory with an instant search bar that filters relatives by first name, middle name, last name, or birthplace in real time.
* **e. Filter Chips and Multi-Option Sorting –** Provides horizontal filter chips with live member counts (All, Living, Deceased, and Missing Parents) and a sort menu to order the directory alphabetically (A to Z) or by birth year (oldest or youngest first).
* **f. Member Profile, Auto-Generated Biography, and Document Attachments –** Displays each relative's profile with an automatic life-events timeline, a 1st-to-4th degree lineal relatives summary, a one-tap Auto-Generate Biography builder in Add and Edit forms, and profile portrait and document attachments.
* **g. Safe Member Archival and Restoration –** Protects against accidental erasure by archiving a deleted member's record and relationship links before removal, allowing the Tree Owner to restore the member cleanly or approve an Editor's restoration request.
* **h. Direct Bloodline Trace Shortcut and Branch Merging –** Provides a one-tap Trace Relationship button on any member's profile to compare them with another relative, and includes a Merge Family Branches tool that combines two separate trees via a 6-character merge code or links disconnected branches within the same tree with a one-tap undo rollback.

### 4. Database Management Module

The Database Management Module serves as the central data storage, synchronization, and encryption layer of the KinTrace application. Powered by Google Cloud Firestore, Firebase Authentication, and a real-time local synchronizer, it manages all user profiles, clan workspaces, member records, and security logs across connected Android devices. Specifically, this module covers the following features:

* **a. User Profile Data Storage –** Stores registered user account records in Cloud Firestore, including full name, email address, birth year, gender, user role, active family tree ID, Terms of Service acceptance timestamp, and onboarding progress.
* **b. Family Tree Workspace and Invite Code Records –** Maintains cloud records for each family tree workspace—storing the tree name, description, ancestral origin, heritage tags, owner ID, member Roles map, privacy settings, 50-member capacity limit, and 6-character invite codes (including 48-hour reunion guest passes).
* **c. Family Member Records and Sensitive Field Encryption –** Stores complete biographical records for every family member and automatically encrypts sensitive personal text fields (birthplace, death place, and biography) on the device before saving them to Cloud Firestore, decrypting them automatically for authorized clan members.
* **d. Bidirectional Relationship Link Integrity –** Maintains consistent two-way relationship pointers across parent, adoptive parent, spouse, former spouse, and child lists, using batch updates and automatic cleanup routines so that adding, editing, or removing a link updates both relatives' records together.
* **e. Real-Time Cloud Synchronization and Offline Persistence –** Uses live Cloud Firestore snapshot listeners and a central tree synchronizer to push family tree updates to all connected family members instantly, while caching records locally on the device so users can view the tree during brief network drops.
* **f. Archival Snapshots, Custom Node Coordinates, and Unsaved Work Guard –** Stores deleted member snapshots for safe restoration, merge rollback snapshots for undoing branch merges, custom X-and-Y canvas coordinates when users manually arrange tree nodes, and an unsaved-work tracker that warns users before logging out with pending edits.

### 5. Relationship Analysis Module

The Relationship Analysis Module serves as the computational core of the KinTrace application. It traces blood and marriage connections between any two selected individuals, calculates legal consanguinity degrees under the Family Code of the Philippines, identifies shared ancestors, and audits the family tree for legal, biological, and chronological conflicts. Specifically, this module covers the following features:

* **a. Dual-Member Selection, Perspective Swap, and Trace History –** Allows users to select Person A and Person B using a spotlight member search sheet, swap their positions with a rotating one-tap button to immediately view the reciprocal kinship title from the other person's perspective, and revisit previous comparisons from a recent trace history list.
* **b. Bloodline, Adoptive, and Marriage Path Tracing –** Searches the family network using shortest-path graph traversal to find the exact connection between any two selected members, tracing across direct biological lines, adoptive parent links, step-family connections, and marriage bridges.
* **c. Step-by-Step Relationship Path Display –** Displays the exact chain of relatives connecting Person A and Person B in a visual step-by-step vertical timeline, labeling each upward ancestor step, downward descendant step, and marriage bridge, with a one-tap button to highlight that exact path on the interactive family tree canvas.
* **d. Civil Degree of Consanguinity Calculation –** Computes the exact numerical degree of blood relationship in accordance with Articles 963 to 966 of the Civil Code of the Philippines by counting every generation step up to the common ancestor and down to the other relative, while explicitly marking marriage-only connections as zero degrees of blood consanguinity.
* **e. Dual-Language Kinship Title and Reference Guide –** Determines the accurate relationship title in both English and Filipino (such as Pinsang Buo / First Cousin, Tiyuhin / Uncle, or Balae / Co-Parent-in-Law) and includes an interactive Relationship Types reference screen covering lineal, collateral, and affinity categories.
* **f. Nearest Common Ancestor Identification –** Pinpoints and displays the specific shared ancestor or ancestral couple from whom both blood-related individuals descend.
* **g. Legal Consanguinity and Chronological Validation –** Validates new and edited relationships against Articles 37 and 38 of the Family Code of the Philippines (blocking incestuous marriages and collateral blood marriages within the 4th civil degree, such as first cousins) and checks birth and death dates to prevent underage marriages, circular ancestry loops, and impossible parent-child age gaps.
* **h. Tree Consistency Audit and Guided Conflict Resolution Wizard –** Scans the entire family tree for broken one-way links, timeline errors, and relationship conflicts, displaying them in a categorized Tree Audit screen (filterable by All, Critical, and Warnings) with a step-by-step Conflict Resolution Wizard to repair each issue.
* **i. Automated Connection and Duplicate Suggestions –** Analyzes unconnected or partially linked records across the tree and suggests possible parent-child links (based on shared last names and 15-to-60-year age gaps), possible sibling links (based on shared last names and 0-to-15-year age gaps), potential duplicate profiles, and missing reciprocal spouse links.

### 6. Report Module

The Report Module generates formatted genealogical documents, visual family tree charts, and portable data files that allow users to preserve, print, and share their family heritage outside the application. Specifically, this module covers the following features:

* **a. Relationship Analysis Report Preview –** Displays a clean, printable summary card of a completed bloodline trace—showing the two compared relatives, their English and Filipino kinship titles, their exact civil degree of consanguinity, their nearest common ancestor, and the step-by-step connection chain.
* **b. Bloodline Relationship Certificate Export (PDF) –** Generates a formal, multi-page PDF document from the Relationship Report screen containing the kinship summary, legal consanguinity degree breakdown, and complete lineage path for printing or sharing.
* **c. Clan Heritage Book Export (PDF) –** Compiles the entire family tree into a multi-page PDF directory organized by generation, complete with a clan summary header and structured biographical entries for every recorded relative.
* **d. High-Resolution Family Tree Poster Export (PNG) –** Renders the complete visual family tree diagram into a high-resolution PNG image file suitable for digital archiving or large-format family reunion printing.
* **e. Standard GEDCOM 5.5.1 Genealogical File Export (.ged) –** Exports all individual records and family union links into a standard GEDCOM 5.5.1 text file (.ged), ensuring full compatibility with external genealogy software.
* **f. Structured Spreadsheet Roster Export (CSV) –** Exports all clan members, their vital dates, birthplaces, and relationship links into a comma-separated values (.csv) file that can be opened in spreadsheet applications such as Microsoft Excel or Google Sheets.
* **g. Post-Export Preview and Native Android Sharing –** Displays an immediate preview and action sheet after every export so authorized users can open the generated file on their device or share it directly through email and messaging apps, while enforcing viewer export restrictions set by the Tree Owner.

### 7. Tree Visualization Module

The Tree Visualization Module renders family member records and relationship links through an interactive, multi-generational graphical canvas. It allows users to explore complex clan hierarchies, trace highlighted bloodlines, view ancestor pedigrees, and customize node layouts smoothly. Specifically, this module covers the following features:

* **a. Interactive Family Tree Main View –** Renders the complete family tree on a zoomable, pannable 2D canvas with color-coded generation bands, distinct connector lines for biological, adoptive, and marriage unions, a live member search bar that pans directly to any selected relative, and a floating minimap radar.
* **b. Trace-Highlighted Path View –** Highlights the active bloodline or marriage path between two traced individuals directly on the tree canvas using glowing connector lines and step badges, while dimming unrelated branches for visual clarity.
* **c. Ancestor Pedigree and Fan Chart View –** Provides a dedicated ancestor view for any selected family member, allowing users to switch between a classic biological pedigree chart and a curved 180-degree ancestral fan chart.
* **d. Interactive Tree Legend and Visual Badges –** Displays an on-screen legend explaining the exact meaning of node border colors (male, female, deceased), union connector lines (current marriage, former spouse, biological child, adoptive child), and generation level indicators.
* **e. Tree Empty State Prompt –** Displays a guided empty-state screen when a newly created workspace has no recorded family members yet, providing a direct button to add the first founding relative.
* **f. Unified Multi-Branch Display –** Renders newly merged family branches and connected in-law lineages together with the main clan hierarchy on a single unified canvas.
* **g. Custom Node Dragging and Layout Reset –** Allows authorized users to long-press and drag individual member nodes to adjust spacing on the canvas, save those custom positions to the cloud, or reset the tree back to its automatic layout with one tap.

### 8. Notification Module

The Notification Module provides real-time in-app alerts, status updates, and categorized notification feeds that keep users informed about workspace access requests, record validation issues, role restrictions, and collaborator activity. Specifically, this module covers the following features:

* **a. Access Request, Role Upgrade, and Approval Notifications –** Notifies the Tree Owner when a user requests to join the family tree, requests an Editor role upgrade, or requests to restore a deleted relative—automatically opening the Pending Requests Hub when tapped—and notifies the requester once their request is approved or rejected.
* **b. Validation, Duplicate Record, and Clan Merge Alerts –** Alerts users during record entry when a relative's profile has conflicting dates, prohibited marriage links, or a possible duplicate match, and sends a cloud notification when two family branches are merged.
* **c. Privacy and Role Permission Alerts –** Displays clear in-app permission warnings whenever a Viewer or unauthorized user attempts a restricted action such as editing records, deleting members, or exporting restricted trees.
* **d. Account Verification and Recovery Notifications –** Provides instant on-screen confirmation and status prompts when sending registration verification emails or password reset links.
* **e. 14-Day Collaborator Inactivity Reminders –** Automatically detects when an assigned Editor or Viewer has had no recorded activity in the family tree for 14 days and sends an inactivity alert to the Tree Owner so they can review collaborator access.
* **f. Categorized Notification Center and Admin Advisories –** Displays all alerts inside a dedicated Notification Center equipped with five filter chips (All, Requests, Tree Edits, Security, and System), swipe-to-dismiss controls, a Mark All Read action, and a home screen banner for system-wide admin advisories.

## Limitations of the Study

Despite the comprehensive capabilities of the KinTrace application, the study is subject to the following technical, operational, and legal boundaries based on its actual system architecture:

* **a. Android-Only Mobile Platform –** The application is developed natively in Kotlin exclusively for Android smartphones and tablets running Android 7.0 (Nougat, API Level 24) or higher. It does not support iOS devices (iPhone or iPad), desktop computers, or web browsers.
* **b. No DNA or Biological Laboratory Testing –** The system determines blood relationships, shared ancestors, and civil degrees of consanguinity strictly from the parent-child and marriage links entered by users. It does not process, analyze, or integrate biological DNA test kits or laboratory paternity results.
* **c. Informational Rather Than Legal or Civil Registry Proof –** While the system computes consanguinity degrees and checks marriage impediments in reference to Articles 37 and 38 of the Family Code of the Philippines and Articles 963 to 966 of the Civil Code, its generated reports and PDF certificates serve solely as educational and informational family records. The application does not connect to the Philippine Statistics Authority (PSA) database and cannot replace official civil registry documents (such as PSA birth or marriage certificates) or formal legal counsel.
* **d. Scope of Philippine Marriage Law Validation –** The marriage validation engine is scoped specifically to general Philippine civil law rules under the Family Code of the Philippines (Articles 37 and 38) and does not evaluate specialized religious canon law dispensations, Muslim Personal Laws (Presidential Decree No. 1083), or foreign marriage jurisdictions.
* **e. Reliance on User-Entered Data Accuracy –** Although the system enforces automated chronological checks, duplicate detection, and prohibited-marriage validations, it cannot independently verify the historical truth of names, birthplaces, or dates typed by users if no conflicting dates exist in the tree.
* **f. No Optical Character Recognition (OCR) for Attached Documents –** While users can attach digital copies of birth certificates, marriage contracts, and government IDs to member profiles, the system stores these files as reference attachments only and does not use Optical Character Recognition (OCR) to automatically read, scan, or extract text from uploaded images or PDFs.
* **g. No External Third-Party Genealogy File Import –** While the system exports family tree records into multiple portable formats and allows merging existing KinTrace trees via a 6-character merge code, it does not support uploading external genealogy files from third-party software to automatically generate a family tree.
* **h. Internet Requirement for Authentication and Cloud Sync –** While Cloud Firestore's local cache allows users to view previously loaded family tree records during brief network interruptions, an active internet connection is required for account registration, email verification, login, password recovery, joining or merging trees via 6-character codes, and syncing real-time changes across family members' devices.
* **i. In-App Notification Center Only (No Background OS Push, SMS, or Email Alerts) –** Aside from account verification and password reset emails handled by Firebase Authentication, all workspace alerts (such as join requests, role upgrades, and 14-day inactivity reminders) are delivered inside the in-app Notification Center when the application is opened, rather than through background operating-system push notifications (Firebase Cloud Messaging) or SMS text messages.
* **j. Compact Cloud Attachment Size Limit –** To comply with Google Cloud Firestore's 1 MB document size limit without requiring a paid external cloud storage server, profile portraits are automatically scaled to 256-pixel thumbnails and attached documents are synced across devices via inline Base64 encoding only when the file is 180 KB or smaller; larger PDF or image attachments remain stored locally on the uploading device.
* **k. Default 50-Member Tree Capacity Limit –** To maintain fast canvas rendering and lightweight cloud synchronization on mobile devices, newly created family trees have a default capacity limit of 50 family members, requiring the Tree Owner to submit an in-app quota expansion request to the System Administrator to add more than 50 members.
* **l. DirectAPK Distribution Instead of Google Play Store Billing –** The application is distributed and updated via direct Android APK installation and an in-app update checker rather than through the commercial Google Play Store, and does not integrate online payment gateways since quota expansions are reviewed and granted directly by the System Administrator.
